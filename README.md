# Smart-Net

Smart-Net adalah inovasi produk berbasis prototipe digital yang dirancang untuk meningkatkan keselamatan nelayan melalui sistem komunikasi lokal tanpa ketergantungan pada jaringan seluler.

## Tentang Proyek

Proyek ini bukan library besar atau aplikasi siap pakai. Ini merupakan kumpulan artefak digital yang berisi materi dokumentasi dan inovasi dasar yang dapat dikembangkan lebih lanjut.

Tujuan umum repositori ini adalah menyimpan materi seperti:
- Dokumen proposal
- Materi presentasi/EXPO
- File pendukung lainnya

## Struktur Repositori

```
smart-net/
├── EXPO/              # Materi presentasi, dokumentasi expo/slide
├── Lainnya/           # File dan aset tambahan pendukung proyek
├── proposal/          # Dokumen proposal proyek
├── (folder lain, jika ada)
└── README.md          # Dokumentasi ini
```

> Struktur ini mencerminkan folder yang terlihat di antarmuka GitHub untuk repo ini. Folder dapat berisi HTML, gambar, file dokumen, atau aset lain yang relevan.

## Tujuan Folder

### EXPO
Folder ini berisi materi presentasi atau dokumentasi visual yang digunakan untuk menunjang presentasi proyek di hari pameran.

### Lainnya
Folder ini menyimpan file tambahan yang tidak termasuk dalam kategori lain, bisa berupa asset atau dokumen pendukung.

### proposal
Folder ini berisi dokumen proposal dan penjelasan awal terkait konsep proyek Smart-Net.
